# 🗞️ NewsCraft.AI 🤖

***"Your Intelligent Journalism Companion"***

> A fully automated, AI-powered newsroom built with Streamlit and OpenAI GPT — designed to research, write, and edit stunning articles in seconds.

---

## 🚀 What I Built Today

Welcome to **NewsCraft.AI**, a smart **journalist agent platform** I developed today to solve one major pain point:

> *"How can we automate credible, personalized article writing using AI while giving users full control over tone, style, and sources?"*

### 💡 Meet NewsCraft.AI

An **interactive web app** where users become **editors-in-chief**—prompting a team of AI agents that:

* 📚 **Research** across the web
* ✍️ **Write** intelligent, high-quality drafts
* 🧠 **Edit** and polish the content—all in one click.

## 🤖 Agent-Based Architecture

🧠 **Multi-Agent System**:

1. 🔍 **Searcher Agent**

   * Queries SerpAPI for high-quality, topical sources
   * Filters by credibility using domains
2. ✍️ **Writer Agent**

   * Scrapes content
   * Drafts longform articles tailored to user selections
3. 🪄 **Editor Agent**

   * Refines grammar, clarity, and consistency
   * Adds headlines, structure, and summaries

---

## 🧩 App Workflow (How It Works)

### Step-by-step user journey:

1. **🔐 Enter API Keys**
   Plug in OpenAI + SerpAPI keys (secure, user-specific).

2. **⚙️ Customize Your Article**
   Define:

   * 📏 Length: Short, Medium, Long
   * ✍️ Style: Formal, Conversational, News, Satirical, etc.
   * 🎯 Audience: General, Students, Professionals, etc.
   * 🌐 Language: English, Hindi, French, etc.

3. **🔎 Input Your Topic or Question**
   E.g., “Impact of AI on investigative journalism”

4. **🔗 Source Selection**

   * App fetches URLs via SerpAPI
   * You pick the sources you trust

5. **🧠 Let the Agents Work**

   * Searcher finds info
   * Writer creates content
   * Editor polishes it

6. **📄 Output**

   * 📰 Full Article
   * 📋 Summary
   * 📌 Key Points
